Privacy Policy

Last updated: October 28, 2026

Purpose

Cetele Kindle is a private, non-commercial utility for sending PDF reading documents from the owner's Gmail account to the owner's Kindle email address. It is intended for use only by the account owner.

Google data accessed

The application requests the Gmail API https://www.googleapis.com/auth/gmail.send scope. This permission is used only to send emails containing PDF attachments at the owner's request or under the owner's configured delivery preferences. The application does not request permission to read, modify, or delete Gmail messages.

Data handling and storage

OAuth credentials and tokens are intended to be stored privately in the owner's local environment and, if deployment is enabled, as protected environment variables on the owner's application hosting service. They are not included in this public website or source code. The application processes the PDF content, recipient Kindle address, and email metadata needed to send each document.

Sharing

Messages and PDF attachments are transmitted to Google Gmail for delivery and to Amazon's Send to Kindle service as the intended recipient. No Google user data is sold or shared for advertising.

Retention and control

The owner controls the generated documents and can disable sending, remove stored credentials, or revoke the application's Google access in Google Account settings. Email copies may remain in Gmail Sent and documents may remain in the Kindle library according to those services' policies.

Security

The application is designed to use OAuth rather than a Gmail password and to keep credentials out of publicly accessible repositories. No system can guarantee absolute security.

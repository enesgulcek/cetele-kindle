Cetele Kindle

Cetele Kindle is a personal-use tool that sends PDF reading documents from its owner's Gmail account to the owner's Amazon Kindle email address.

The tool uses Google's Gmail API with the gmail.send permission solely to send PDF attachments. It does not read the inbox, access contacts, or delete messages. It is not offered to the public.
